# Vendor manuals

| File | Document | Used by |
|---|---|---|
| `HPD322_stepper_driver_manual.pdf` | HPD322 stepper-driver manual (enable polarity, microstep DIP switches, pulse timing ≥ 2.5 µs, 400 kHz maximum pulse rate) | the motion part of this firmware |
| `VL53L0X_manual.pdf` | VL53L0X laser time-of-flight ranging manual | **not** used by this firmware; it belongs to a ranging sensor that was evaluated during development (see `docs/07-history.md`) |

Both files are the original documentation of their manufacturers and are
included here for reference only. All rights remain with the respective
manufacturer; if you redistribute this repository, check whether you are
allowed to pass the PDFs on, or remove this directory and link to the
manufacturer instead.
